   최종 원자료:
     results/20261028/pen_perspectives_2026_verified/

   초기 독립 측정은 8.775초. 따라서 여기서의 전파 비용은 약 9–11초였다.
   real-grid electron PEN 40 fs 계산을 수행한 것이 아니다.

2. 짧은 preview 영상: 각 경우 9 frames (81개 중 stride10), 5 movie families.
   여섯 조건 모두 출력 성공, jobs3 wall time 155.79초, 총 약95.14 MiB.
   이 결과는 최종 일부 표시/확률적분 수정 이전의 개발 benchmark이고,
   최종 물리 결과 경로와 혼동하지 않는다:
     results/20261028/pen_perspectives_2026_benchmark/

3. 최종 전체 영상: DSE off 3개, 각 81 frames × 5 movies 완료.
   jobs3 동시 실행에서 case당 469.01, 473.00, 471.72초 (공유 CPU 경합 포함).
   각 case 전체 출력(원자료+PNG+MP4): zero17.34, weak19.19, strong21.78 MiB.
   parent Python peak RSS 약478–482 MiB/case (ffmpeg 자식 메모리는 별도).
   실제 MP4를 ffprobe로 확인: 81 frames, 4.05초/20fps, 짝수 해상도.
   PNG의 초기/중간/끝 및 실제 B MP4 중간 프레임을 직접 열어 확인했다.
   DSE on의 최종 전체 영상은 사용자의 서버 실행 요청 확인 후 중단했다.
   on/plots의 일부 파일은 미완성이므로 최종 영상으로 사용하지 말 것.

총 6개를 서버에서 실행할 때의 예상치 (실측과 추정 구분)
----------------------------------------------------
40fs, 0.5fs 저장, nq-display160, DPI85, snapshot140, jobs3 기준:
  TDSE + 원시 계수: 로컬 실측 약11초, 15.6 MiB.
  PNG + 30개 MP4 포함: 로컬 관측 속도로 약16분, 총120–150 MiB 예상.
  서버 CPU/파일시스템 성능은 측정하지 않았다. 실무적으로 20–40분과 여유500 MiB
  정도를 잡으면 된다. 16 GiB의 여유 디스크라면 이 소형 모델은 충분히 들어간다.
  50fs는 위 비용의 약1.25배가 첫 추정이며, 실제로 실행 완료했다고 주장하지 않는다.
  --nq-display500, DPI 상향, --every-fs0.25는 렌더링 시간/용량을 늘린다.
  jobs1은 메모리를 절약하지만 렌더링 총 벽시계 시간이 길어진다.
  GPU를 사용하지 않는다. jobs3는 CPU/RAM을 사용하고 GPU11GB 제한과 무관하다.
